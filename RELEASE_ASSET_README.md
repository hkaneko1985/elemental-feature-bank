# v1.0.0 archival release asset

`elemental-feature-bank-v1.0.0-data.zip` is the fixed release asset for version 1.0.0.

Upload this exact ZIP file, without recompressing or modifying it, to:

1. the `v1.0.0` Release of
   https://github.com/hkaneko1985/elemental-feature-bank; and
2. the corresponding Zenodo Dataset record.

Using the same byte-identical file at both locations enables the TV-040
SHA-256 equivalence check.

The GitHub repository and this ZIP are not separate projects. The repository is
the version-controlled project location; this ZIP is a downloadable, immutable
snapshot attached to the repository's GitHub Release and archived on Zenodo.
