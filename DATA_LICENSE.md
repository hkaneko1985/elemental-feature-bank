# Dataset rights and licence notice

## Scope

This repository combines project-authored curation, metadata, documentation, and scripts with numerical values derived from multiple third-party sources. **No single blanket licence is asserted over all numerical values.**

The public matrices contain only source records classified `GREEN` in `source_license_policy.csv`. This classification means that an explicit distribution route or reuse basis was identified during research-data due diligence; it does not remove source-specific attribution, notice, database-right, or jurisdictional obligations.

## Project-authored material

The repository owner may choose a licence for the following original contributions after authorship and institutional approval are finalized:

- build and validation scripts written for this project;
- feature-selection and interpretability annotations;
- project-authored metadata fields and documentation;
- the original selection and arrangement of the released data, to the extent protectable.

`LICENSE_CODE.template` is a proposed MIT licence for project-authored code only. Rename it to `LICENSE` only after replacing the copyright holder and receiving approval.

## Third-party numerical values

Reuse of numerical values remains subject to the original source terms. Consult:

- `element_source_registry.csv`
- `source_license_policy.csv`
- `THIRD_PARTY_LICENSES.md`
- `ATTRIBUTION.md`

The absence of a restriction in this repository is not a representation that no rights exist.

## Excluded values

Values from `AMBER` or `HOLD` sources are not included in the public matrices. Acquisition and reconstruction scripts are provided for local use where the user has lawful access to the upstream assets. Locally reconstructed values must not be redistributed merely because the scripts are public.
