# Repository name and URL proposals

## Recommended

### `elemental-feature-bank`

```text
https://github.com/hkaneko1985/elemental-feature-bank
```

**Why:** concise, memorable, consistent with the feature-bank design, and broad enough to cover both interpretable and learned representations.

## Alternatives

1. `interpretable-elemental-features`  
   Emphasizes the interpretable matrix, but underrepresents the `others` matrix.

2. `elemental-feature-dataset`  
   Neutral and descriptive, but more generic.

3. `provenance-aware-elemental-features`  
   Closely matches the paper's novelty, but is relatively long.

4. `elemental-descriptor-bank`  
   Familiar materials-informatics terminology; slightly less aligned with learned embeddings.

5. `elemental-representation-bank`  
   Strong for learned representations, but less direct for named physical properties.

## Recommended project name

**Elemental Feature Bank**  
Optional abbreviation: **EFB**

## Recommended repository description

> Provenance-aware elemental feature dataset for 118 elements, with 822 interpretable and 944 auxiliary/learned features, licence-gated optional reconstruction, and technical validation.
