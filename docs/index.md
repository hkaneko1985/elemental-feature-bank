# Elemental Feature Bank

A provenance-aware elemental feature dataset for 118 chemical elements.

- **822 interpretable features** from licence-cleared sources
- **944 auxiliary, learned, or encoded features** from licence-cleared sources
- **3,434 optional features** excluded from public value files and reconstructable locally
- **40-item Technical Validation**: 33 PASS, 5 PASS WITH NOTE, 2 DEFERRED, 0 FAIL

Start with the [English README](../README.md) or [Japanese README](../README_ja.md).


## Tier review

An AI-assisted blinded second pass achieved 97.69% exact agreement and Cohen's κ=0.9607 across all 5,200 catalogue features. See [`validation/tier_review/`](../validation/tier_review/).
