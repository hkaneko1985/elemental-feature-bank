## Citation practice

1. Report the exact dataset version or DOI.
2. List the feature blocks used in the analysis.
3. Cite the software/distribution route and the primary scientific source for each used block.
4. Describe formulas for project-derived features.
5. Do not describe locally reconstructed AMBER/HOLD values as part of the public release.
